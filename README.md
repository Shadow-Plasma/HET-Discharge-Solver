# Julia-HET — Hall Effect Thruster 1D Simulation

A Julia simulation harness for a custom-designed **7 mN Hall Effect Thruster (HET)**, built on [HallThruster.jl](https://github.com/UM-PEPL/HallThruster.jl) v0.23.2. The suite solves the 1D discharge-channel physics (ionisation rate, electron energy, ion density) and delivers exit-plane plasma profiles ready for downstream plume modelling.

This repository covers **Step 1** of a five-step computational framework for HET plume–spacecraft interaction:

| Step | Description | Status |
|------|-------------|--------|
| 1 | Discharge kernel — 1D axial solver (HallThruster.jl) | ✅ This repo |
| 2 | Near-field plume expansion | 🔜 |
| 3 | Backflow flux map onto spacecraft surfaces | 🔜 |
| 4 | CEX ion trajectory integration | 🔜 |
| 5 | End-of-life material erosion | 🔜 |


## Further Work in "Discharge Kernel — 1D Axial Solver"

| # | Study | What it involves | Why it matters |
|---|-------|-----------------|----------------|
| 1 | Operating envelope mapping | Add a voltage sweep (200–600 V) combined with the existing mass-flow sweep into a 2D performance grid | Standard characterisation output for any thruster paper; thrust, Isp, power, and efficiency as functions of both Vd and ṁ |
| 2 | Breathing mode analysis | FFT of the raw `sol` time series (`Id(t)`, `ji(t)`) to extract oscillation frequency and amplitude | Breathing mode (~10–30 kHz) modulates ion energy periodically, directly relevant to plume interaction |
| 3 | Anomalous transport sensitivity | Sweep `TwoZoneBohm(α₁, α₂)` coefficients and plot thrust, Isp, Te_exit, and plume angle response | Largest source of model uncertainty in HET simulation; rigorous Uncertainty Quantification (UQ) is what EP labs look for |
| 4 | Magnetic field topology study | Vary B-peak location (70–95% of L_ch) and Gaussian width σ parametrically | Shows how the ionisation zone moves and acceleration sharpens, non-trivial physics beyond parameter running |
| 5 | Propellant comparison | Run the same geometry on Kr vs Xe (HallThruster.jl supports both) | Kr is actively replacing Xe in small satellite HETs due to cost and availability, directly industry-relevant |
| 6 | Geometry scaling study | Scale geometry across 1–20 mN (keeping w/R_mean and L/w constant) and track efficiency, Isp, and power density | Demonstrates understanding of thruster scaling physics useful for design space exploration |
| 7 | Wall loss quantification | Extract radial ion loss flux to channel walls vs axial position as a function of Vd and B-field | Natural bridge to Step 5 (erosion), connects discharge physics to end-of-life behaviour |

## Repository Structure

| File | Role |
|------|------|
| `My_HET.jl` | Core simulation: geometry, B-field, Config, SimParams, run, thrust sweep, 4-panel plots, Excel export |
| `2D axisymmetric cross section.jl` | Packs `sol_avg` outputs into a `viz_data` named tuple for downstream scripts |
| `Visualise thruster 2d.jl` | 8-panel 2D axisymmetric cross-section visualiser with zone shading and plume divergence cones |
| `Derived_Quantities.jl` | 6-panel derived physics (E-field, ion velocity, ionisation source, Hall parameter, Larmor radius, E×B drift) + Excel export with live formulas |

## Usage

All four scripts run in a **single REPL session** in order. Each script reads from variables left in scope by the previous one — do not `include` them in a fresh REPL without first running `My_HET.jl`.

```julia
# Step 1 — Run the simulation
# Defines: sol, sol_avg, my_geometry, my_config, z_vec, B_vec, z_peak
julia> include("My_HET.jl")

# Step 2 — Pack outputs into viz_data struct
julia> include("2D axisymmetric cross section.jl")

# Step 3 — 2D axisymmetric visualisation
julia> include("Visualise thruster 2d.jl")

# Step 4 — Derived plasma quantities
julia> include("Derived_Quantities.jl")
```

Expected console output from `My_HET.jl`:

```
Running simulation...
── Results ───────────────────
Thrust            : 7.xx mN
Discharge current : x.xx A
Power             : xxx.x W
Isp               : xxxx s
Anode efficiency  : xx.x %
```

## Thruster Design Parameters

| Parameter | Value | Notes |
|-----------|-------|-------|
| Inner radius | 40.9 mm | R_mean − w/2 |
| Outer radius | 50.9 mm | R_mean + w/2 |
| Channel width | 10 mm | w/R_mean ≈ 0.31 (healthy: 0.25–0.35) |
| Channel length | 25 mm | L/w = 2.5 (healthy: 2.0–3.0) |
| Discharge voltage | 300 V | Isp ∝ √Vd |
| Mass flow rate | 0.65 mg/s | Thrust ∝ ṁ (linear) |
| Peak B-field | ~120 Gauss | B_peak ∝ 1/R_mean |
| B-peak location | 90% of L_ch | Ionisation zone placed near exit |
| Target thrust | ~7 mN | Nominal operating point |

**Quick scaling guide:**
- More thrust → increase `anode_mass_flow_rate` (linear)
- Higher Isp → increase `discharge_voltage` (√ effect)
- Rescaling thruster → keep `w/R_mean ≈ 0.31`, `L/w ≈ 2.5`, `B ∝ 1/R_mean`
- Double Vd: Isp × 1.41, Thrust × 1.41, Power × 2
- Double ṁ: Thrust × 2, Isp unchanged, Power × 2

## Physics Models

**Discharge solver:** HallThruster.jl 1D axial, explicit time integration, `EvenGrid(50)` cells, dt = 2 ns, duration = 0.2 ms.

| Model | Implementation |
|-------|---------------|
| Anomalous electron transport | `TwoZoneBohm(1/160, 1/16)` |
| Ionisation rate coefficient k_iz | Goebel & Katz (2008) Appendix E piecewise fit for Xe |
| Plume divergence (Method 1) | Voltage-utilisation: α = arccos(√(1 − Te_exit/Vd)) |
| Plume divergence (Method 2) | ji 50%-decay half-angle: α = arctan(r_c / Δz₅₀) |
| Hall parameter Ω_e | ω_ce / ν_en, e–n collision from Xe cross-sections |
| E×B drift | v_ExB = \|E\| / B |
| Ion velocity | Energy conservation from local potential drop |

**Zone boundaries (auto-derived from geometry):**

| Zone | Extent |
|------|--------|
| Neutral fill | 0 → 60% L_ch |
| Ionisation | 60% L_ch → z_B_peak |
| Acceleration | z_B_peak → L_ch (exit plane) |
| Plume | L_ch → domain end |
