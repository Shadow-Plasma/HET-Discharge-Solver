# Code — Julia Suite

Julia simulation scripts for the 1D Hall Effect Thruster discharge kernel.
Run these in order in a single REPL session — each script reads variables left in scope by the previous one.

---

## Files

| # | File | Description |
|---|---|---|
| 2 | `My_HET.jl` | Core simulation — geometry, B-field, Config, SimParams, baseline run, thrust sweep, 4-panel plots, Excel export |
| 3 | `2D axisymmetric cross section.jl` | Extracts and bundles plasma profile data into a clean `viz_data` named tuple for downstream visualisation |
| 4 | `Visualise thruster 2d.jl` | 8-panel 2D axisymmetric visualiser — zone shading, plume divergence cones, geometry schematic |
| 5 | `Derived_Quantities.jl` | Derived plasma physics — E-field, ion velocity, Hall parameter, E×B drift, ionisation source + Excel export |

---

## Usage

```julia
# Run all scripts in order in the same REPL session
julia> include("My_HET.jl")
julia> include("2D axisymmetric cross section.jl")
julia> include("Visualise thruster 2d.jl")
julia> include("Derived_Quantities.jl")
```

> **Important:** All scripts must be run in the same REPL session in order.
> Each script reads variables left in memory by the previous one and will fail in a fresh REPL.

**Expected console output from `My_HET.jl`:**

```

── Results ───────────────────
Thrust            : 7.xx mN
Discharge current : x.xx A
Power             : xxx.x W

```

```

── Plasma Profile ────────────────────────
```

## Outputs

| File | Generated by | Description |
|---|---|---|
| `MyHET_7mN_results.png` | `My_HET.jl` | 4-panel plot: B-field, Te, plasma potential, ion current density |
| `MyHET_7mN_results.xlsx` | `My_HET.jl` | Plasma properties · Performance summary · Thrust sweep · B-field profile |
| `viz_data` | `2D axisymmetric cross section.jl` | Named tuple in REPL memory — passed to downstream visualiser |
| `MyHET_2D_viz.png` | `Visualise thruster 2d.jl` | 8-panel 2D axisymmetric visualisation, 1600×1800 px |
| `MyHET_derived.png` | `Derived_Quantities.jl` | 6-panel derived plasma physics plot |
| `MyHET_derived_data.xlsx` | `Derived_Quantities.jl` | 8-sheet Excel with derived quantities and formula columns |
