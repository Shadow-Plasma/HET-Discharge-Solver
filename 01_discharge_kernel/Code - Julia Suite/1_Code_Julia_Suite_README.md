# Code — Julia Suite

Julia simulation scripts for the 1D Hall Effect Thruster discharge kernel.
Run these in order in a single REPL session — each script reads variables left in scope by the previous one.

---

## Files

| File | Description |
|---|---|
| `My_HET.jl` | Core simulation — geometry, B-field, Config, SimParams, baseline run, thrust sweep, 4-panel plots, Excel export |
| `2D axisymmetric cross section.jl` | Extracts and bundles plasma profile data from the 1D discharge simulation into a clean `viz_data` named tuple for downstream 2D visualisation |

---

## Usage

```julia
# Step 1 — Run the core simulation
julia> include("My_HET.jl")

# Step 2 — Extract and bundle plasma data for visualisation
julia> include("2D axisymmetric cross section.jl")
```

> **Important:** Run both scripts in the same REPL session in order.
> `2D axisymmetric cross section.jl` reads variables left in memory by `My_HET.jl`
> and will fail in a fresh REPL.

**Expected console output from `My_HET.jl`:**

```
Running simulation...
── Results ───────────────────
Thrust            : 7.xx mN
Discharge current : x.xx A
Power             : xxx.x W
Isp               : xxxx s
Anode efficiency  : xx.x %
```

**Expected console output from `2D axisymmetric cross section.jl`:**

```
── Geometry ──────────────────────────────
── Magnetic Field ────────────────────────
── Plasma Profile ────────────────────────
── Operating Conditions ──────────────────
── viz_data bundle ready ─────────────────
Data extraction complete. Ready for visualizer.
```

---

## Outputs

| File | Generated by | Description |
|---|---|---|
| `MyHET_7mN_results.png` | `My_HET.jl` | 4-panel plot: B-field, electron temperature, plasma potential, ion current density |
| `MyHET_7mN_results.xlsx` | `My_HET.jl` | Plasma properties · Performance summary · Thrust sweep · Magnetic field profile |
| `viz_data` | `2D axisymmetric cross section.jl` | Named tuple in REPL memory — passed to downstream visualiser |
